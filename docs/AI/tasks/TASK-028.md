# TASK-028: 手机端响应式三板块 Tab 视图与终端辅助键盘适配 (Mobile Responsive 3-Tab Layout & Touch/Keyboard Adaptation)

---

## 1. 任务背景与目标

Remora 在桌面端采用了类似 VS Code 的三栏/分屏布局（ActivityBar、Sidebar、Editor、Terminal 借助拖拽 Splitter 并存展示）。但在手机设备小屏幕上，多面板并存会导致各板块极度局促，无法正常阅读代码和操作终端。

同时，手机端用户输入依托于系统自带的虚拟键盘（输入法/软键盘），而软键盘普遍缺乏终端操作必不可少的控制键（Esc, Tab, Ctrl, Alt, 方向键等），导致无法退出 vim、无法补全命令、无法调出历史记录。

本任务目标：
1. **小屏幕响应式检测与三板块 Tab 切换**:
   - 在 `layoutStore` 引入 `isMobile`（监听窗口宽度 `< 768px` 与移动设备环境）与 `mobileTab`（"workspace" | "editor" | "terminal"）。
   - 在移动端模式下，彻底收拢 Splitter 多面板，改为**单屏单板块 Tab 呈现**（一次只展示一个板块），极大化释放屏幕空间。
2. **移动端底部导航栏 (`MobileTabBar`)**:
   - 底部固定导航栏，一键切换 [📁 工作区]、[📝 编辑器]、[⚡ 终端]。
   - 附带智能徽标（编辑器脏文件数/打开文件数、终端在线会话数、服务器在线状态点）。
3. **智能交互联动与移动端专用按钮**:
   - 在移动端的文件树中点击文件时，除了打开文件，自动无缝切换当前 Tab 至 [📝 编辑器]，流畅进入代码浏览或编辑。
   - 编辑器 TabBar 右侧增加常驻高亮的“💾 保存 (Ctrl+S)”触控按钮，解决手机没有物理快捷键保存代码的痛点。
4. **终端移动端专用辅助按键栏 (`TerminalMobileBar`)**:
   - 在终端下方提供横向滑动的移动端辅助按键栏。
   - 提供 `ESC`、`TAB`、`CTRL`（支持修饰切换，如 `Ctrl+C`、`Ctrl+D`、`Ctrl+Z`）、`ALT`、方向键（`↑` `↓` `←` `→`）以及常用符号（`/`, `~`, `|`, `-`, `:`）。
   - 按键直接向底层 SSH PTY 发送真实 ANSI 控制转义序列，令移动端使用 vim、nano、htop、bash 达到与桌面端一致的便捷性。
5. **视口与虚拟键盘适配**:
   - `index.html` 增加 `viewport-fit=cover` 与 `maximum-scale=1.0, user-scalable=no`。
   - 全局视口容器采用 `h-[100dvh]`，动态自适应手机软键盘弹出/收起后的可视区域变化。

---

## 2. 验收标准

1. 浏览器或移动设备宽度小于 768px 时，界面自动转为三板块 Tab 模式。
2. 点击底部 Tab 栏可在工作区、编辑器、终端之间顺畅切换，一次仅渲染一个核心板块。
3. 在工作区文件树点击文件，自动切换至编辑器 Tab。
4. 编辑器具备触控“保存”按钮，点击正常保存修改。
5. 终端提供辅助键盘栏，点击 ESC、TAB、方向键及 Ctrl 组合键能正常向终端发送控制信号。
6. 前端 TypeScript 类型检查与 Vite 打包 100% 成功。
