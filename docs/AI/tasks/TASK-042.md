## 2. 完成内容

1. **核心理念与竞品对比**:
   - 深入对比 Remora 与传统 SSH 终端客户端 (Tabby / Termius) 及 VS Code Remote-SSH 的差异；
   - 突出 0 远程服务端侵入、极低内存占用、强断网自愈、TMUX 深度集成与 Android 移动端保活的差异化优势。

2. **核心特性矩阵系统梳理**:
   - **SSH 连接与安全**: 密码、RSA/Ed25519/ECDSA 私钥、SSH Agent、`~/.ssh/config` 导入、SSH 命令一键分词解析、系统钥匙串安全存储、多服务器并发与活动工作区调度。
   - **远程项目文件树**: 严格懒加载、依赖智能忽略、文件增删改、远端安全回收站、本地文件/文件夹拖拽上传与同名冲突处理、SFTP 僵尸会话死锁自愈与前台恢复。
   - **轻量代码编辑器**: CodeMirror 6、One Dark 主题、单击预览与双击常驻 Tab、`Ctrl+S` 保存、远程 `mtime` 冲突检测、本地 Buffer 零丢失保障。
   - **高性能终端**: xterm.js 5、Tauri 2 二进制流直推、WebGL 加速、`SIGWINCH` 尺寸自适应、CJK / IME 输入法修复、远程代理与 No Proxy 白名单自动注入、快捷指令条与分组导入导出。
   - **TMUX 深度集成**: 可视化 TMUX 会话管理器、单会话单终端独占、**无感静默接入 (Stealth Attach)** 流式过滤、断网重连自动恢复现场。
   - **移动端全功能响应式**: Android 3-Tab 视图、DOM 级保活机制 (Keep-Alive)、辅助虚拟键盘浮条、Android 沙盒 SQLite 与凭据持久化。
   - **传输与桌面集成**: 后台流式分块传输器、Linux 桌面快捷方式与 `Ctrl+Shift+N` 多窗口、GitHub Release 自动更新器。
